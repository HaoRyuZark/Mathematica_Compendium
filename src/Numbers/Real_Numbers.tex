\chapter{Real Numbers}

\section{Axiom Definition}

A way of defining the \emph{real numbers} is via the \emph{Cauchy sequences}. Another way is via
the axioms of a field with the order axioms and the \emph{completeness axiom}.

The following axioms apply for any \(a, b, c \in \R\):

\begin{itemize}

	\item \emph{Associativity:} \((a \circ b) \circ c = a \circ (b \circ c)\) for all \(a,b,c \in \R\).

	\item \emph{Commutativity:} \(a \circ b = b \circ a\) for all \(a,b \in \R\).

	\item \emph{Identity Element for multiplication:} There exists \(1 \in \R\) such that \(a \odot 1 = 1 \odot a = a\) for all \(a \in \R\).

	\item \emph{Identity Element for addition:} There exists \(0 \in \R\) such that \(a \oplus 0 = 1 \oplus a = a\) for all \(a \in \R\).

	\item \emph{Inverse Element for multiplication:} For every \(a \in \R\), there exists \(a^{-1} \in \R\) such that \(a \odot a^{-1} = a^{-1} \odot a = 1\).

	\item \emph{Inverse Element for addition}: For every \(a \in \R\), there exists \(-a \in \R\) such that \(a \oplus -a = -a \oplus a = 0\).

	\item \emph{Distributivity:} \(a \odot (b \oplus c) = (a \odot b) \oplus (a \odot c)\) and/or \((b \odot c) \oplus a = (b \odot a) \oplus (c \odot a)\).

\end{itemize}

\subsection{Properties Derived from the Axioms}

\begin{itemize}

	\item The neutral and inverse elements of the addition and multiplication are well defined.

	\item \(a + b = c\) and \(a + c = 0 \implies b = c\)

	\item \(a \cdot 0 = 0\)

	\item \(-a = (-1)a\)

	\item \(-(-a) = a\)

	\item \((-1)^2 = 1\)

	\item \(\left(a^{-1}\right)^{-1} = a, \forall \in \R, a \ne 0\)

\end{itemize}

The proofs of these statements are in the chapter about fields.

\section{Order Axioms}

We also define the following order axioms for the real numbers:

\begin{enumerate}[label=\Roman*.]

	\item \emph{Trichotomy:} Exactly one of the following holds:

	      \[
		      a < b, \quad a = b, \quad a > b
	      \]

	\item \emph{Transitivity:} If \( a < b \) and \( b < c \), then \( a < c \).

	\item \emph{Additive Compatibility:} If \( a < b \), then \( a + c < b + c \).

	\item \emph{Multiplicative Compatibility:} If \( a < b \) and \( c > 0 \), then \( ca < cb \).

\end{enumerate}

\subsection{Properties Derived from the Order Axioms}

\begin{enumerate}

	\item \(x < y \iff y - x > 0\)

	\item \(x > 0 \iff -x < 0\)

	\item \(x < y \iff -y < -x\)

	\item \(xy > 0 \iff (x > 0 \land y > 0) \lor (x < 0 \land y < 0)\)

	\item \(x \neq 0 'iff x^2 > 0\)

	\item \((x < y) \land (z < 0) \implies (xz > yz)\)

	\item \(x > 0 \iff \frac{1}{x} > 0\)

	\item \(x^2 < y^2. x \ge 0. y > 0 \implies x < y\)

	\item \((x < y) \land (z < w) \implies (x + z < y + w)\)

\end{enumerate}

\textbf{Proof I:}

\[
	x < y \iff x - x < y - x \iff 0 < y - x \iff y - x > 0
\]

\QED

\textbf{Proof II:}

\[
	x > 0 \iff x - x > 0 - x \iff -x < 0
\]

\QED


\textbf{Proof III:}

\[
	x < y \iff x - y < y - y \iff x - y < 0 \iff x - x  - y < 0 - x \iff -y < -x
\]

\QED


\textbf{Proof IV:}

From \(xy > 0 \), we know by the sign rules that either \(x > 0\) and \(y > 0\) or \(x < 0\) and \(y < 0\), a direct argument.
From our other direction we can use the sign rules to prove that \(xy > 0\) if either \(x > 0\) and \(y > 0\) or \(x < 0\) and \(y < 0\).

\QED

\textbf{Proof V:}

\(x \neq 0 \iff x < 0 \lor x > 0 \), and from the sign rules we know that \(x^2 > 0\) if either \(x < 0\) or \(x > 0\).
The other direction uses the same argument.

\QED

\textbf{Proof VI:}

Let \(x < y\) and \(z < 0\). To be able to use multiplication we need to multiply by a positive number, so we multiply by \(-z\) which is positive.
Then we have

\begin{align*}
	x < y & \iff -y < -x             \\
	      & \iff (-y)(-z) < (-x)(-z) \\
	      & \iff yz < xz
\end{align*}

\QED

\textbf{Proof VII:}

\[
	x > 0 \iff x x^{-1} > 0 x^{-1} \iff 1 > 0 x^{-1} \iff x^{-1} > 0
\]

\QED

\textbf{Proof VIII:}

For the case \(x = 0\) we have \(0^2 = 0\) and \(0^2 < y^2\) for any \(y > 0\).

For the case \(x > 0\) we have:

\begin{align*}
	x^2 < y^2 & \iff x^2 +xy < y^2 + xy  \\
	          & \iff x(x + y) < y(y + x) \\
	          & \iff x < y
\end{align*}

Since both are positive and not zero, we can divide by \(x + y\) and \(y + x\).

\QED

\textbf{Proof IX:}

\begin{align*}
	x < y      & \iff x + z < y + z //
	\iff x + z & < y + z < y + w
\end{align*}

By the transitivity of the order relation, we have \(x + z < y + w\).

\QED

\section{Existence of Solutions}

Given \(a,b \in \R\), then

\[
	!\exists x \in \R, \text{ such that, } a + x = b
\]

Also, if \(a \ne 0\)

\[
	!\exists x \in \R, \text{ such that, } ax = b
\]

\textbf{Proof:}

For the first proposition, let \(x = -a + b\)

\begin{align*}
	a + x & = a -a + b \\
	      & = b
\end{align*}

For the second, let \(x = a^{-1}b\)

\begin{align*}
	ax & =  a a^{-1} b \\
	   & = 1 \cdot b
\end{align*}

\QED

\section{The Completeness Axiom}

All non-empty \emph{upper-bounded} subsets of the real numbers have a \emph{supremum} \(s \in \R\). We will
explain what this means in the next section.

\section{Supremum, Infimum, Maximum and Minimum for Fields}

The \emph{supremum} \(\sup\) of a set \(A \subseteq \field\) is the
least upper bound: the smallest real number \(s\) such that \(a \le s\) for all \(a \in A\).

\[
	x < s, \forall x \in A
\]

\[
	x < s', \forall x \in A \implies s' \ge s
\]

For the \emph{infimum} we have

\[
	x > s, \forall x \in A
\]

\[
	x > s', \forall x \in A \implies s' \le s
\]


The \emph{maximum} is the largest element in the set, if it exists.

The \emph{minimum} is the smallest element in the set, if it exists.

Finally, we define \(\sup \emptyset := - \infty\) and \(\inf \emptyset := +\infty\).

\textbf{Example I:}

For \(A = (0,1)\):

\begin{itemize}

	\item \(\sup(A) = 1\) (not in \(A\)).

	\item \(\inf(A) = 0\) (not in \(A\)).

	\item \(\max(A)\) and \(\min(A)\) do not exist.

\end{itemize}

We can prove this in the following way:

For the supremum, we can see that 1 satisfies the condition of being an upper bound, now we need to
prove that it is the least upper bound. Let \(s' < 1\) be another upper bound, then we can take \(x = \frac{s' + 1}{2}\) which is
an element of \(A\) and \(x > s'\). This means that \(s'\) is not an upper bound, and therefore 1 is the least upper bound.

For the infimum, it is similar. We need to prove that \(k' > 0\) is not a lower bound, by using \(x = \frac{k' + 0}{2}\) which is an element of \(A\) and \(x < k'\).
This means that \(k'\) is not a lower bound, and therefore 0 is the greatest lower bound.

Since, both 0 and 1 are not in \(A\), then \(\max(A)\) and \(\min(A)\) do not exist.

\QED

\textbf{Example II:}

Prove that \(\sup \left\{\frac{n}{n + 1} \mid n \in \N\right\} = 1\).

To prove this, we need to show that 1 is an upper bound, and then that for all \(\varepsilon > 0\), \(a - \varepsilon\) is not
an upper bound.

\begin{align*}
	1     & \ge \frac{n}{n + 1} \\
	n + 1 & \ge n
\end{align*}

Thus, 1 is in fact an upper bound.

For the second part, let \(\varepsilon > 0\), and we want to prove that \(\exists n \in \N : \frac{n}{n + 1} > 1 - \varepsilon\).

\begin{align*}
	\frac{n}{n + 1} > 1 - \varepsilon      \\
	\varepsilon >  1 - \frac{n}{n + 1}     \\
	\varepsilon >  \frac{n + 1 - n}{n + 1} \\
	\varepsilon >  \frac{1}{n + 1}         \\
	n + 1 >  \frac{1}{\varepsilon}         \\
	n  >  \frac{1}{\varepsilon}  - 1
\end{align*}

By the Archimedean principle, we know that we can always find a larger natural number such that \(n > \frac{1}{\varepsilon} - 1\)

Now we can reverse the steps in the inequality, and we will get our original inequality.

\QED

\subsection{Alternative Characterization of the Supremum}

Given a non-empty set \(A \subseteq \field\). Then \(s \in \field\) is a supremum of \(A\) if and only if

\[
	(\nexists s \in A, s < x) \land (s' \in \R, s' < s \implies !\exists x \in A, x > s')
\]

\section{Uniqueness of Suprema and Infima}

Given a ordered field \(\field\). If it has a supremum or minimum they are unique.

\textbf{Proof:}

Let \(s_1\) and \(s_2\) be suprema of \(\field\) then \(s_1 > a\) for all \(a \in \field\) and by definition the upper bound \(s_1 \ge s_2\). By now taking
\(s_2\) as the supremum, then \(s_2 \ge s_2\); also \(s_1 = s_2\).

\section{Properties of Suprema and Infima}

For non-empty sets \(A, B \subseteq \R^+\):

\begin{itemize}

	\item \(\sup(AB) = \sup(A) \cdot \sup(B)\)

	\item \(\inf(AB) = \inf(A) \cdot \inf(B)\)

	\item \(\sup (A + B) = \sup(A) + \sup(B) \)

	\item \(\inf (A + B) = \inf(A) + \inf(B) \)

	\item \(\sup (A / B) = \sup(A) / \inf(B)\)

	\item \(\sup (-A) = - \inf (A)\)

	\item \(\inf (-A) = - \sup (A)\)

\end{itemize}

For the sake of completeness, we will prove one of these properties:

\textbf{Proof:}

By definition, \(\forall ab \in AB\) the following holds:

\[
	ab \le \sup A \cdot \sup B \implies \sup AB \le \sup A \cdot \sup B
\]

Because \(\sup A\) and \(\sup B\) do not necessarily belong to \(A\) or \(B\). With this, we already have
half of the proof. Now we need to prove that \(\sup AB \ge \sup A \cdot \sup B\).

Start with

\begin{align*}
	ab & \le \sup AB           \\
	a  & \le \frac{\sup AB}{b}
\end{align*}

Therefore, \(\frac{\sup AB}{b}\) is an upper bound of \(A\). This means that:

\[
	\sup A \le \frac{\sup AB}{b} \implies \sup A \cdot b \le \sup AB
\]

From this we can also derive that

\[
	\sup A \cdot b \le \sup AB \implies b \le \frac{\sup AB}{\sup A}
\]

Thus, because \(\frac{\sup AB}{\sup A}\) is an upper bound of \(B\) we have that:

\[
	\sup B \le \frac{\sup AB}{\sup A} \implies \sup A \cdot \sup B \le \sup AB
\]

Combining both parts of the proof we have that:

\[
	\sup AB = \sup A \cdot \sup B
\]

\QED

The other proofs can be proven using similar arguments.

\section{Definition of Complete}

Given a field \(\field\). If each upper-bounded, non-empty subset of \(\field\) has a supremum we denote \(\field\) as
\emph{complete}.

As a consequence, if all non-empty below-bounded subsets have an infimum then the set is also \emph{complete}.

\textbf{Proof:}

Due to the equivalence of \(x \le y\) and \(-y \le -x\), we can define \(M' = \{-x \mid x \in M\}\) with \(\sup M' = - \inf M\).

\section{Minima in the Real Numbers}

As a consequence of the \emph{completeness axiom}, each non-empty lower-bounded subset of real numbers has a minimum.

\textbf{Proof:}

The main idea is that the supremum times minus 1 of a set is the minimum of another set.

We define \(- A := \{-a \mid a \in A\}\), then \(-A \ne \emptyset\) and is upper-bounded.
By definition \(s\) is less or greater than all the elements of the set \(A\).

\begin{align*}
	s  & \le a, \forall a \in A  \\
	-s & \ge -a, \forall a \in A
\end{align*}

Thus, \(-s = \sup-A\).

Now we want to prove that \(-\sup-A\) is first, the lower bound of \(A\) and second, it is the greatest upper bound.

For the first part

\begin{align*}
	\sup-A    & \ge -a \forall a \in A \\
	- \sup -A & \le a \forall a \in A
\end{align*}

Thus, \(-\sup-A\) is in fact a lower bound of \(A\). For the second part let us
assume that there exists some element \(s\) such that \(s > -\sup-A\) and \(s \le a, \forall a \in A\), then

\[
	-s < \sup -A  \text{ and } -s \ge -a, \forall a \in A
\]

This is a contradiction because we have an upper bound, which is not an upper bound. Therefore,
\(-\sup-A\) is the infimum of \(A\).

\QED

\section{Approximation of the Supremum}

Given a non-empty, upper-bounded set \(A \subseteq \R\) and \(s = \sup A\). Then there is for each \(y < s\)
an \(x \in A\), such that

\[
	y < x \le s
\]

An analogous theorem can be written for the minimum as well.

\textbf{Proof:}

If \(x \in A\), then the proof is completed. For the case \(s \notin A\), if there existed some
\(y^* \in \R\) where \(y^* < s\) and \(y^* \ge x\) for all \(x \in A\), then we still have a contradiction to
the assumption that \(s\) is the supremum of \(A\).

\QED

\section{Supremum of the Naturals}

\(\N\) is not upper-bounded.

\textbf{Proof:}

Assume \(a = \sup\N\). Since \(\N \subset \R\) is not empty, it has an upper-bound by
the completeness axiom.

By the definition of the supremum, \(a - 1 \in \N\) is not an upper-bound of \(\N\), therefore
\(a - 1 < k, k \in \N\).

Then, the following also applies

\[
	a < k + 1.
\]

This is a contradiction to the assumption that \(a\) is our supremum, thus our assumption has been
proven false.

\section{The Archimedean Principle}

If \(a\) and \(b\) are real numbers with \(a > 0\), then there exists \(n \in \N\) such that \(na > b\).

Equivalently, for any real number \( x \in \R \), there exists a natural number \( n \in \N \) such
that \( n > x = \frac{b}{a} \).

\textbf{Proof:}

We prove the Archimedean Principle by contradiction.

Assume that there exists some real number \( x \in \R \) such that \( n \leq x \) for all
\( n \in \N \). That is, \(x\) is an upper bound for the set \( \N \subset \R\), backed up
by the Completeness Axiom of the real numbers.

Let \( s = \sup(\N) \) be the least upper bound of \( \N \). Then,

\[
	s - 1 < s \implies \exists m \in \N \text{ s. t. } m > s - 1.
\]

But, if we add 1 to both sides, we get

\[
	s < m + 1 \in \N.
\]

This is a contradiction to the assumption that \(s\) is the supremum of the Naturals. Hence, there
is no real number \(x\) which is greater than all natural numbers.

\QED

\subsection{Equivalent Formulation}

For any \( \varepsilon > 0 \), there exists \( n \in \N \) such that \( \frac{1}{n} < \varepsilon \).

Applications:

\begin{enumerate}

	\item \textbf{Density of Rational Numbers:} The Archimedean Principle helps in proving that between
	      any two real numbers, there exists a rational number.

	\item \textbf{Limits and Infinitesimals:} It ensures that sequences like
	      \( \left\{ \frac{1}{n} \right\}\) converge to 0, foundational in real analysis and calculus.

	\item \textbf{Bounding Functions:} It is used in analysis to show that functions do not grow faster
	      than natural numbers in certain contexts.

	\item \textbf{Non-Existence of Infinitely Small Numbers:} The principle implies that real numbers do
	      not contain infinitesimals (nonzero numbers smaller than all \( \frac{1}{n} \)), distinguishing
	      \( \R \) from non-standard number systems.

\end{enumerate}

\textbf{Example:}

Prove that \(\forall \varepsilon > 0, \exists N \in \N: \frac{1}{n} < \varepsilon, \forall n \ge N\).

We know that

\begin{align*}
	\frac{1}{N}               & < \varepsilon                            \\
	\varepsilon > \frac{1}{N} & \ge \frac{1}{n} \text{ by transitivity } \\
	\varepsilon               & > \frac{1}{n}.
\end{align*}

We also get \(N > \frac{1}{\varepsilon}\).

And by the Archimedean Principle, we let \(b = 1\), \(a = \varepsilon\) and \(n = N\). Then by
transitivity we get our proof.

\QED

\section{Eudoxus's Theorem}

For all positive real numbers \(x\), there exists an \(n \in \N\) such that

\[
	\frac{1}{n} < x.
\]

\textbf{Proof:}

\(x \in \R_{> 0} \implies \frac{1}{x} \in \R_{> 0}\). By the Archimedean property, \(\exists n \in \Z_{0 >}, \frac{1}{x} < n\).
Equivalently \(\frac{1}{n} < x\).

\QED

\section{Density of the Rationals in the Reals}

For each pair \(x, y \in \R\) there exists some \(\frac{m}{n} \in \Q\) such that

\[
	x < \frac{m}{n} < y.
\]

\textbf{Proof:}

Since \(y > x\), then \(y - x > 0\), by the Archimedean principle \(n(y - x) > 1\). Choose the smallest \(m \in \Z\)
such that

\[
	m - 1 \le nx < m \implies x < \frac{m}{n}
\]

For the second half, we need to prove that our \(m\) satisfies \(m < ny\) by using our stablished
inequality \(m - 1 \le nx\) and the following reformulation of \(n(y - x) > 1\) to \(x < y - \frac{1}{n}\)

\begin{align*}
	m - 1 \le nx & \iff m \le nx + 1                     \\
	             & \iff m < n (y - \frac{1}{n}) + 1 = ny
\end{align*}

Hence we get \(\frac{m}{n} < y\).

\QED

\section{Existence of Nth Roots}

For each \(x \in (0, \infty), !\exists  r \in (0, \infty) \text{ s. d. } r^n  =x\). Also, \(\sqrt[n]{x}:= r\) and we call \(x \mapsto \sqrt{x}\) the \emph{root function}.

\textbf{Proof:}

\emph{Uniqueness}: Let \(r_1, r_2 \in \R^{+}\) such that \(r_1^n = r_2^n = x\) with \(r_1 < r_2 \implies r_1^n < r_2^n\), hence there
is a contradiction and \(r_1 = r_2\). For the case \(r_1 > r_2\) the conclusion is the same.

\emph{Equality}:

Let \(T = \{r \in (0, \infty) \mid r^n < x\}\)

First to prove that the set \(T\) is not empty. By the density of the rationals in the reals we know that
for any given \(0 = y < \frac{m}{n} < x\), we can find a rational in between, hence let \(r^n = \frac{m}{n}\).
Therefore \(T\) has a supremum \(s\) such that \(s^n = x\). We will prove that the supremum can not be less or greater that the root
of \(x\).

Let \(s^n < x\), then \(s \in T\), but since they are both real number we can apply the density principle again to find another
real number which satisfies \(r^n < x\), hence our \(s\) is not an upper bound and we have a contradiction.

Let Let \(s^n > x\), then \(s \notin T\). Choose \(\varepsilon\) such that \((s - \varepsilon)^n < x \implies (s - \varepsilon) \in T\), then we have
found a smaller lower-bound of \(T\); also leading contradiction.

Hence, \(s^n = x\) and we call \(\sqrt[n]{x} = n\).


\QED

\section{Real Polynomials}

A polynomial \(p\) of degree \(n\) is a function \(p: \R \to \R\) defined as

\[
	p(x) = a_n x^n + a_{n - 1} x^{n - 1} + \ldots + a_1 x + a_0 = \sum_{k = 0}^{n} a_k x^k
\]

\section{Order of Real Polynomials}

For a polynomial \(p\) of degree \(n\) where \(a_n > 0\) and \(0 < \varepsilon < 1\), there is
\(r \in \R_+\) such that

\begin{enumerate}

	\item \((1 - \varepsilon) a_n x^n \le p(x) \le (1 + \varepsilon) a_n x^n\) for all \(x \ge r\)

	\item \((1 - (-1)^n \varepsilon) a_N x^n \le p(x) \le (1 + (-1)^n \varepsilon) a_n x^n\) for all \(x \le -r\)

	\item \((1 - \varepsilon)|a_n||x|^n \le |p(x)| \le (1 + \varepsilon) |a_n| |x|^n\) for all \(|x| \ge r\)

\end{enumerate}

Also, there exists \(M > 0\) such that

\[
	|p(x)| \le M |x|^n, \quad \forall x \in \R, \, |x| \ge r
\]
\textbf{Proof I:}

\begin{align*}
	p(x) & \le |a_0| x^0 + |a_1| x^1 + \ldots + |a_{n - 1}|x^{n - 1} + a_n x^n                                \\
	     & \le (|a_0| + |a_1| + \ldots + |a_{n - 1}|) x^{n - 1} + a_n x^n                                     \\
	     & = a_n x^n \left(1 + \frac{|a_0| + \dots + |a_{n - 1}|}{a_n x}\right) \le (1 + \varepsilon) a_n x^n
\end{align*}

For the last inequality, we need to choose \(r\) such that \(\frac{|a_0| + \ldots + |a_{n - 1}|}{a_n x} \le \varepsilon\).

\[
	r = 1 + \frac{|a_0| + \ldots + |a_{n - 1}|}{\varepsilon a_n}
\]

For the other direction, we can use the same argument:

\begin{align*}
	p(x) & \ge -|a_0| x^0 - |a_1| x^1 - \ldots - |a_{n - 1}|x^{n - 1} + a_n x^n                               \\
	     & \ge -(|a_0| + |a_1| + \ldots + |a_{n - 1}|) x^{n - 1} + a_n x^n                                    \\
	     & = a_n x^n \left(1 - \frac{|a_0| + \dots + |a_{n - 1}|}{a_n x}\right) \ge (1 - \varepsilon) a_n x^n
\end{align*}

\QED

\section{Absolute Value for Real Numbers}

The \emph{absolute} is defined as

\[
	|x| := \sqrt{x \cdot x}.
\]

\subsection{Distance}

\begin{itemize}

	\item \(|x| \ge 0, \forall x \in \R\)

	\item \(|x| = 0, \implies x = 0\)

	\item \(|\alpha x| = |\alpha| |x|, \forall x, \alpha \in \R\)

	\item \(|x + y| \le |x| + |y| \forall x,y \in \R\)

\end{itemize}

We define the \emph{distance} between two real numbers as

\[
	d(x,y) = | x - y |
\]

with the following properties:

\begin{itemize}

	\item \(d(x,y) \ge 0, \forall x,y \in \R\)

	\item \(d(x,y) = 0, \iff x = y \)

	\item \(d(x,y) = d(y,x)\)

	\item \(d(x,y) \ge d(x,y) + d(z,y), \forall x,y \in \R\)

\end{itemize}
