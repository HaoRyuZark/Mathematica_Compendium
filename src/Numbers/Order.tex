\chapter{Order}

\subsection{Partially Ordered Classes}

A \emph{partially ordered class} is a pair of objects \(\inner{A}{R}\) where \(A\) is a class and \(R\) is 
and order relation in \(A\). Remember that an order relation is one which is : reflexive, antisymmetric and transitive.

\subsection{Lexicographical Ordering}

Let \(A\) and \(B\) be partially ordered classes; by the \emph{lexicographical ordering} of \(A \times B\) we 
mean the following order relation in \(A \times B\): If \((a_1, b_1), (a_2, b_2) \in A \times B\) and \((a_1, b_1) \le (a_2, b_2) \) 
if and only if

\[
	a_1 < a_2 
\]

or 

\[
	a_1 = a_2 \land b_1 \le b_2
\]

\subsection{Antilexicographical Ordering}

Let \(A\) and \(B\) be partially ordered classes; by the \emph{antilexicographical ordering} of \(A \times B\) we 
mean the following order relation in \(A \times B\): If \((a_1, b_1), (a_2, b_2) \in A \times B\) and \((a_1, b_1) \le (a_2, b_2) \) 
if and only if

\[
	b_1 < b_2 
\]

or 

\[
	b_1 = b_2 \land a_1 \le a_2
\]

\subsection{Comparable}

Let \(A\) be a partially ordered class. Tow elements \(x, y \in A\) are considered \emph{comparable} if 
either \(x \le y\) or \(y \le x\); otherwise, they are said to \emph{incomparable}.

\subsection{Fully Ordered Subclass}

Let \(A\) be a partially ordered class, and let \(B \subseteq  A\). If two elements of \(B\) are comparable, 
then we call \(B\) a \emph{fully ordered subclass of \(A\)}, or \emph{linearly ordered subclass of \(A\)}, or more 
commonly, a \emph{chain} of \(A\). If every two elements of \(A\) are comparable, then \(A\) is also considered as such.


\textbf{Example:} 

Let \(C\) and \(D\) be chains of \(A\) and \(B\) respectively, prove that \(A \times B \text{ lex. sorted } \implies C \times D \text{ is chain of } A \times B\).

\textbf{Proof:}

By the contraposite, if \(C \times D\) is not a chain of \(A \times B\), then there some element \((c,d)\) can not be compared, because \((c, d)\) can 
not be compared, but \((c,d) \in A \times B\), then \(A \times B\) can not lexicographicaly sorted.

\QED

\subsection{Initial Segments}

Let \(A\) be a partially ordered class and suppose \(a \in A\). The \emph{initial segment of \(A\) determined by \(a\)} is the 
class \(S_a\), defined as follows: 

\[
	S_a = \{x \in A \mid x < a\}.
\]

Initial segments are transitive, which means that if we have an initial segment of an initial segment, then the last one  is also 
an initial segment of the parent class.

\subsubsection*{An initial segment of an initial segment of a class is an initial segment of the same class}

\textbf{Proof:}

Let \(P = \{x \in A \mid x < a\}\) for some \(a \in A\) and let \(Q = \{p \in P \mid p < c\}\) for some \(c \in P\). By definition 
\(Q \subseteq A\). Because \(c \in A\) it is clear that \(Q\) is an initial segment of \(A\).

\QED

\subsection{Cuts}

If \(A\) is a partially ordered class, then a \emph{cut} of \(A\) is a pair \((L, U)\) of nonempty subclasses of \(A\) with 
the following properties:

\begin{itemize}

	\item \(L \cup U = \emptyset \land L \cup U = A\).
	\item If \(x \in L \land y \le x \implies y \in L\).
	\item If \(x \in U \land y \ge x \implies y \in U\).

\end{itemize}

The two second conditions simply tell us that, we can compare its elements.

\textbf{Example:} 

Given the partially ordered classes \(A\) and \(B\), and let \(A \times B\) be ordered antilexicographically. Prove that 
\((L, U) \text{ is a cut of } B \implies (A \times L, A \times U) \text{ is a cut of } A \times B\)

\textbf{Proof:}

Let \((L,U)\) be a cut of \(B\) and define

\[
	L' = A \times L, \qquad U' = A \times U .
\]

We show \((L',U')\) is a cut of \(A \times B\) under the antilexicographical order.

\textbf{Nonempty, disjoint, and covering:}

Suppose \(L' \cap U' \neq \emptyset\). Then,

\[
	\exists (x,y) \in L' \cap U': x \in A \land (y \in L \lor y \in U)
\]

Hence, \(L \cap U \neq \emptyset\), a contradiction. Therefore, they must be disjoint.

For the covering, we use the distributive property of the Cartesian product under set union, 
\(A \times (L \cup U) = A \times L \cup A \times U = A \times B\).

\textbf{Downward closure of \(L'\):}

Let \((a_1,b_1) \in A \times L\) and \((a_2,b_2) \le (a_1,b_1)\).

By antilexicographical order,

\[
	b_2 < b_1 \text{ or } (b_2 = b_1 \land a_2 \le a_1).
\]

Since \(b_1 \in L\) and \(L\) is downward closed in \(B\), we have \(b_2 \in L\).
Hence \((a_2,b_2) \in A \times L\).

\textbf{Upward closure of \(U'\):}

Let \((a_1,b_1) \in A \times U\) and \((a_1,b_1) \le (a_2,b_2)\).
Then

\[
	b_1 < b_2 \quad \text{or} \quad (b_1 = b_2 \land a_1 \le a_2).
\]

Since \(b_1 \in U\) and \(U\) is upward closed in \(B\), we have \(b_2 \in U\).
Thus \((a_2,b_2) \in A \times U\).

Therefore \((A \times L, A \times U)\) is a cut of \(A \times B\).

\QED

\subsection{Order Preserving Functions}

Let \(A\) and \(B\) be partially ordered classes; a function \(f: A \to B\) is said to \emph{increasing} or 
\emph{decreasing}, if it satisfies the following condition: For every two elements \(x, y \in A\), 

\[
	x \le y \implies f(x) \le f(y).
\]

\subsection{Isomorphism}

If \(f\) is bijective and \(x \le y \iff f(x) \le f(y)\) for every two elements \(x \in A, y \in B\), we call it an \emph{isomorphism}.


\subsection{Strictly Increasing Function}

We consider \(f\) strictly increasing if it satisfies that:

\[
	x < y \implies f(x) < f(y).
\]

\textbf{Example:} 

Prove that if \(f : A \to B\) is an injective, increasing function, then it is strictly increasing.

\textbf{Proof:}

Suppose it is not increasingly increasingly. The negation is \(x < y \implies f(x) \ge f(y)\).

Now we have that \(x \le y \implies f(x) \ge f(y) \land  x \le y \implies f(x) \le f(y) \iff f(x) = f(y)\) for some \(x, y \in A\), hence we have a contradiction 
to the injectivity.

\QED

\subsection{Order by Inverses}

Let \(A\) and \(B\) be partially ordered classes and let \(f: A \to  B\) be a bijective function. Then \(f\) is 
an isomorphism if and only if \(f: A \to B\) and \(f^{-1}: B \to A\) are increasing functions. 

\textbf{Proof:}

\[
	f(x) \le f(y) \implies f^{-1}(f(x)) \le f^{-1}(f(y)) \implies x \le y
\]

By the isomorphic property we get the increasing property for \(f\) and also for \(f^{-1}\) because else for \(f(x) \le f(y): y \le x\) violates our initial condition that \(x \le y\)

\[
	x \le y \implies f(x) \le f(y) \implies f^{-1}(f(x)) \le f^{-1}(f(y))
\]

Thus, \(f\) and \(f^{-1}\) are increasing functions.

\QED

\subsection{Common Isomorphism on Partially Ordered Classes}

Let \(A\), \(B\) and \(C\) be partially ordered classes. 

\begin{itemize}

	\item \(I_A: A \to A\) with \(I_A(x) = x, \quad x \in A\) is an isomorphism. 
	\item If \(f: A \to B\) is an isomorphism, then \(f^{-1}: B \to A\) is an isomorphism.
	\item If \(f: A \to B\) and \(g: B \to C\) is an isomorphism, then \(g \circ f: A \to C\) is an isomorphism.

\end{itemize}

\textbf{Proof I:}

Let \(I_A = f\), for \(x, y \in A\) we have that \(x \le y\) gives us \(x < y \iff f(x) < f(y)\) and \(x = y \iff f(x) = f(y)\).

\QED

\textbf{Proof II:}

In one of our previous results we got that \(f^{-1}\) is increasing if and only \(f\) is an isomorphism. We prove that \(f^{-1}\) is also one by 
assuming it is not, then \(\exists y \in B: f(x) \ne y, \forall x \in A\) which is a contradiction.

\QED

\textbf{Proof III:}

We keep in mind the bijectivity of \(f\) and \(g\) and state the following

\[
	x \le y \iff f(x) \le f(y) \iff g(f(x)) \iff (f(y))
\]

\QED

\textbf{Example:} 

Given the isomorphism \(f:A \to B\), if \((L,U)\) is a cut of \(A\), then \((f(L), f(U))\) is a cut of \(B\).

\textbf{Proof:}

Suppose \((f(L), f(U))\) is not a cut, then \(y \in f(L) \cap f(U)\), then \(y \in f^{-1}(f(L)) \cap f^{-1}(f(U))\) but this is a contradiction. 
Therefore, \((f(L), f(U))\) must be disjoint.

For the covering, we use a similar argument \(f(L) \cup f(U) \neq B\), then \(f\) would not be bijective, hence, another contradiction.

For the downward and upward closure, we know that our function targets the whole set \(B\) and by its isomorphic properties 
it respects the order. Therefore, this properties are also satisfied. 

\QED

\subsection{Isomorphic Definition}

Let \(A\), and \(B\) be partially ordered classes. If there exist and order preserving isomorphism between the two 
classes, we say that \(A\) is \emph{isomorphic} with \(B\).

Note, that the isomorphic property allows us to define an equivalence relation between classes.

\subsection{Convex}

Let \(A\) be partially ordered class and \(C \subseteq A\). If for \(a \in C\) and \(b \in C\) the following holds 
\(a \le x \le b, \forall x \in C\), then we consider \(C\) \emph{convex}.

\subsubsection*{Properties}

Let \(A\), and \(B\) be partially ordered classes

\begin{itemize}

	\item If \(C \subseteq B\) is convex and \(f: A \to B\) is an increasing function, then \(f^{-1}(C)\) is also convex.
	
	\item If \(H\) is the functional equivalence relation, and \(f: A \to B\) is an increasing function, then all 
	equivalence classes of \(A / H\) are convex subsets of \(A\).

\end{itemize}

\textbf{Proof I:}

Given  \(f(a), f(b) \in C\), then using the properties of the increasing functions we get \(f^{-1}(f(a)) \le f^{-1}(f(x)) \le f^{-1}(f(b))\) which gives us \(a \le x \le b\) which 
is the definition of a convex class.

\QED

\textbf{Proof II:}

Given the equivalence relation given by the function \(f\) we have that for every member of an arbitratry equivalence class 
\(f(a) = f(x) = f(b)\) can be written as \(f(a) \le f(x) \le f(b)\) hence we the defintion of convex classes.

\QED

\subsection{Maximal Element}

An element \(m \in A\) is considered \emph{maximal element} of \(A\) under the partially order relation \(R\) if \(\forall x \in A\) 

\[
	x \le m
\]

and if 

\[
	x \ge m \implies x = m.
\]

Or equivalently \(m\) under the relation rule does not relate to anything except itself:

\[
	\forall (m, y) \in R \implies m = y \text{ or equivalently } (x, m) \in R, \forall x \in A.
\]

\subsection{Minimal Element}

An element \(m \in A\) is considered \emph{minimal element} of \(A\) under the partially order relation \(R\) if \(\forall x \in A\) 

\[
	x \ge m
\]

and if 

\[
	 x \le m \implies x = m.
\]

Or \(m\) is under the relation rule does not relate to anything except itself: 

\[
	\forall (x, m) \in R \implies m = x \text{ or equivalently } (m, x) \in R, \forall x \in A.
\]

\subsection{Upper Bound}

Let \(B \subseteq A\). An \emph{upper bound} of \(B\) in \(A\) is an element \(a \in A\) such that 
\(a \ge x, \forall x \in B\). Equivalently

\[
	\forall x \in B, (x, a) \in R.
\]

\subsubsection*{Set of Upper Bounds}

Let \(B \subset A\), we define the function \(v\) as 

\[
	v(B) := \{a \in A \mid a \ge x, \forall x \in B \}.
\]

\subsection{Lower Bound}

Let \(B \subseteq A\). A \emph{lower bound} of \(B\) in \(A\) is an element \(a \in A\) such that 
\(a \le x, \forall x \in B\). Equivalently

\[
	\forall x \in B, (a, x) \in R
\]

\subsubsection*{Set of Lower Bounds}

Let \(B \subset A\), we define the function \(\lambda\) as 

\[
	\lambda(B) := \{a \in A \mid a \le x, \forall x \in B\}.
\]

\subsection{Maximum}

An element \(x\) is a partially ordered class \(A\) is a \emph{maximum} if 

\[
	(a, x) \in R, \forall a \in A.
\]

\subsection{Minimum}

An element \(x\) is a partially ordered class \(A\) is a \emph{minimum} if 

\[
	(x, a) \in R, \forall a \in A.
\]

\subsection{Supremum and Infimum}

Given a partially ordered class \(B \subseteq A\), the least upper bound is called the \emph{supremum} \(s \in A\) and defined as:

\[
	\forall b \in B, (b, s) \in R \text{ and } \forall a \in A, [(\forall b \in B, (b, a) \in R) \implies (s, a) \in R],
\]

and the greatest lower bound is its \emph{infimum} \(i \in A\) is defined as:

\[
	\forall b \in B, (i, b) \in R \text{ and } \forall a \in A [(\forall b \in B, (a, b) \in R) \implies (a, i) \in R].
\]

\subsection{Duality}

Let \(\mathscr{S}\) be a statement about partially ordered classes with \(\ge, \le\). If we replace the occurrences of 
\(\ge, \le\) with their contrary, then the resulting statement \(\mathscr{S}'\) is called the \emph{dual} of \(\mathscr{S}\).

We know that given an order relation \(G\) on \(A\), then \(G^{-1}\) is also an order relation on \(A\). For the dual this means that for 
any true statement on \(G\) the dual of the statement is also true for \(G^{-1}\).

\subsection{Greatest and Least Elements under Inclusion}

If \(A\) has a greatest element \(a\), and \(B\) has a greatest element \(b\), and \(B \subseteq A\), then 

\[
	b \le a.
\]

\textbf{Proof:} 

\[
	a \ge x, \forall x \in A \implies a \ge b, \forall b \in B \implies a \ge b
\]

\QED 

\textbf{Dual:} If \(A\) has a least element \(a\), and \(B\) has a least element \(b\), and \(B \subseteq A\), then 

\[
	b \ge a.
\]

\subsection{Upper and Lower Bounds under Inclusion}

Let \(B\) and \(C\) be subclasses of \(A\). If \(B \subseteq C\), then 

\[
	v(C) \subseteq v(B).
\]

\textbf{Proof:} 

\(x \in v(C) \implies x \geq y, \ \forall y \in C\) because \(y \in B \implies b \in C\), then \( x \geq y, \forall y \in B \implies x \in v(B).\)

The opposite is not always true, due to the fact that if \(z \in V(B)\), such that \(z \in C\), but \(z \notin v(C)\), which 
is possible if \(z\) is not an upper bound of \(C\), then the theorem does not hold.

\QED 

\textbf{Dual:} If \(B \subseteq C\), then 

\[
	\lambda(C) \subseteq \lambda(B).
\]

\subsection{Suprema and Infima under Inclusion}

Let \(B\) and \(C\) be subclasses of \(A\), and suppose that \(B\) and \(C\) each has a \(\sup\) in \(A\). If \(B \subseteq C\), then 

\[
	\sup B \leq \sup C.
\]

\textbf{Proof:} 

By the dual of the greatest element under inclusion applied to \(v(C) \subseteq v(B)\),

\[
	\sup(B) \le \sup(C).
\]

\QED 

\textbf{Dual:} If \(B\) and \(C\) each has an \(\inf\) in \(A\), and if \(B \subseteq C\), then 

\[
	\inf B \geq \inf C.
\]

\subsection{Relation between a Set and Bounds of Bounds}

Let \(B\) be a subclass of \(A\). Then 

\[
	B \subseteq v(\lambda(B)).
\]

\textbf{Proof:} Suppose \(x \in B\); for each \(y \in \lambda(B)\), \(y \leq x\); hence \(x \in v(\lambda(B))\).

\QED 

\textbf{Dual:} 

\[
	B \subseteq \lambda(v(B)).
\]

\subsection{Infimum via Lambda Function}

Let \(B \subseteq A\), then

\[
	\sup(\lambda(B)) \in A \implies \inf(B) \in A \land \inf(B) = \sup(\lambda(B))
\]

\textbf{Dual:} \(\inf(v(B)) \in A \implies \sup(B) \in A \land \sup(B) = \inf(v(B))\).

\textbf{Proof:}

Let \(s = \sup(\lambda(B)),\ \forall b \in B,\ s \le b\); hence, \(s\) is a lower bound of \(B\). Suppose \(\inf(B) \neq s\), then \(s > \inf(B) \lor s < \inf(B)\).

Case \(s > \inf(B)\): this leads to a contradiction because if \(s \in A\) and  \(s\) is a lower bound of \(B\), but it is greater than its infimum then 
\(\inf(B)\) can not be the greatest lower bound of \(B\), which does not make sense by the definition.

Case \(s < \inf(B)\): \(\inf(B)\) is a lower bound of \(B\); therefore, \(\inf(B) \in \lambda(B)\). If \(s < \inf(B)\) then \(s\) can not be the supremum 
of \(\lambda(B)\) since there exists a greater element in it; hence \(s = \inf(B)\).

\QED

\subsection*{Example Exercises}

1. Prove that given \(B \subseteq A\), \(\sup(B) = b \in A \implies \lambda(v(B)) \cap v(B) = \{b\}\)

\textbf{Proof:}

By definition \(b \in v(B)\). Also, by the definition of \(\lambda(v(B))\):

\[
	\{a \in A \mid x \le b, \forall b \in v(B)\};
\]

we can guarantee that \(b \in \lambda(v(B))\). It is leftover to prove that the intersection only consists of \(b\). 

Suppose that there also exists another \(x\) in the intersection such that \(x \ne b\), then \(x \in v(B) \land x \in \lambda(v(B))\). 

If \(x \in v(B)\) and \(x \ne b\), then \(x < b\) or \(x > b\) which when handled separately lead to the following conclusion: 

If \(x < b\), then \(b\) is not the least upper bound of \(B\) which is a contradiction to the definition of the supremum. Hence, by the \(\land\) in our original 
statement, we arrive at the conclusion that such an \(x\) can not exist.

\QED

2. Let \(B \subseteq A\), \(C \subseteq A\), then \(\sup(B) = \sup(C) \implies v(B) = v(C)\).

\textbf{Proof:}

By definition for \(\sup(B) \ge b, \forall b \in B\), and also \(\sup(B) \in v(B)\), but because it is the least upper bound we can write 

\[
	v(B) = \{a \in A \mid a \ge \sup(B)\}
\]

Therefore, if \(\sup(B) = \sup(C) = s\), then \(v(B) = \{a \in A \mid a \ge s\}\), and because they are shared then 
\(v(C) = \{a \in A \mid a \ge s\}\)

\QED 

3. Suppose \(B \subseteq A\); prove that \(v(B) = v(\lambda(v(B)))\). 

For \(x \in v(B)\) holds that \(x \ge b, \forall b \in B\), then for \(y \in \lambda(v(B))\) holds \(y \le z, \forall z \in v(B)\) which 
implies that \(y \le b, \forall b \in B\). Finally, if \(y \le b, b \in B\), then for \(w \in v(\lambda(v(B)))\) it must be true that 
\(w \ge y, \forall y \in \lambda(v(B))\), which by transitivity implies that \(w \ge b, \forall b \in B\); hence, \(v(B) = v(\lambda(v(B)))\).

\QED

\subsection{Lattices}

Let \(A\) be a partially ordered class. If every doubleton \(\{x, y\}\) in \(A\) has a 
\(\sup\) and \(\inf\) then \(A\) is called a \emph{lattice}.

When dealing with lattices, we denote \(\sup(\{x, y\}):= x \lor y\) and \(\inf(\{x, y\}) := x \land y\).

\subsubsection*{Properties}

For \(a, b \in A\)

\begin{enumerate}

	\item \(a \le a \lor b\) and \(b \le a \lor b\)
	
	\item \(a \ge a \land b\) and \(b \ge a \land b\)

	\item If \(a \le c\) and \(b \le c\), then \(a \lor b \le c\)
	
	\item If \(a \ge c\) and \(b \ge c\), then \(a \land b \ge c\)
	
	\item \(a \lor a = a\) and \(a \land a = a\)

	\item \(a \lor b = b \lor a\) and \(a \land b = b \land a\)

	\item \((a \lor b) \lor c = a \lor (b \lor c)\) and \((a \land b) \land c = a \lor (b \land c)\)
	
	\item \((a \lor b) \land a =  a\) and \((a \and b) lor a = a\)

\end{enumerate}

\textbf{Proof 3:}

To prove: \(a \lor a = a\) and \(a \land a = a\). 

\(a \lor a \ge x, \forall x \in \{a\}\). Using the defintion of the infimum we can also prove 
the statement for infimum.

The other statements are easily proved by cases. 

\QED

\subsection{Definition of Less Than}

Let \(A\) be a \emph{lattice}, we define the symbol \(\le\) as:

\[
	x \le y \iff x \lor y = y
\]

\textbf{Example I:}

Given a lattice \(A\) with \(\le\), prove that it is an order relation. 

\emph{Reflexivity:} \((a, a) \in R\) because \(a \le a\) implies \(a \lor a = a\).

\emph{Antisymmetry}: \(a \le b \implies a \lor b = b\) if by supposition \(b \le a\), then \(b \lor a = a\), but our property 
tells us that \(a \lor b = b \lor a\); therefore, \(a = b\).

\emph{Transitivity}: \((a, b), (b, z) \in R \implies (a, z) \in R\), if \(a \lor b = b\) and  \(b \lor z = z\), then 
\(a \le b\) and \(a \le z\), hence; \(a \le b \lor z = z \implies (a, z) \in R\).

\QED

\textbf{Example II:}

Given \(a \le b\) and \(c \le d\), prove that \(a \lor c \le b \lor d\).

Proceeding by cases note that: \(a \ge c\) delivers \(a \lor b \lor d\). If \(b \ge c\), then \(a \le b\); 
if \(d \ge b\) then \(a \le d\) by transitivity. Similarly, for the case \(a \lor c = c\), then if \(b \ge d\) gives  us 
\(c \le b\); else if \(b \le d\) then \(c \le b \le d\).

\QED

\subsubsection{Distributive Laws for Lattices}

\begin{itemize}

	\item \(x \land (y \lor z) \ge (x \land y) \lor (x \land z)\).
	
	\item \((x \lor y) \land z \le (x \lor y) \land (x \lor z)\).

\end{itemize} 


\subsection{Sublattices}

Let \(A\) be a lattice, and let \(B\) be a subclass of \(A\). If 

\[
	x \in B \text{ and } y \in B \implies x \lor y \in B \text{ and } x \land y \in B,
\]

the \(B\) is called a \emph{sublattice} of \(A\).

\subsection{Boolean Algebra}

A \emph{Boolean algebra} is defined to be a lattice \(A\) with the following additional properties:

\begin{enumerate}

	\item \(\exists 0 \in A\) and \(1 \in A\) such that \(x \lor 0 = x\) and \(x \land 1 = x\).

	\item \(\forall x \in A, \exists \overline{x} \in A: x \land \overline{x} = 0 \text{ and } x \lor \overline{x} = 1\).

	\item \(x \lor (y \land z) = (x \lor y) \land (x \lor z)\) and \(x \land ( y \lor z) = (x \land y) \lor (x \land z)\)
	Let \(A\) be a partially ordered class; \(A\) is called a \emph{complete lattice} if every subclass of \(A\) has a \(\sup\).
	Alternatively, if every subclass of \(A\) has an \(\inf\).

\end{enumerate}

In other words \(1\) the biggest and \(0\) the smallest element in \(A\).

\subsubsection*{Distributive Lattices}

A \emph{distributive lattice} is boolean algebra.

\subsection{Order in Fields}

An \emph{ordered field} is a field \(\field\) equipped with a total order \( < \) that is compatible with 
the field operations + and \( \cdot \). That is, the order satisfies both algebraic and ordering

\subsubsection{Order Axioms for Fields}

A field \(F\) is called an \emph{ordered field} if it satisfies the following properties for all 
\( a, b, c \in F \):

\begin{enumerate}[label=\Roman*.]
    
	\item \emph{Trichotomy:} Exactly one of the following holds:
 
		  \[
 	   			a < b, \quad a = b, \quad a > b
    	   \]

    \item \emph{Transitivity:} If \( a < b \) and \( b < c \), then \( a < c \).

    \item \emph{Additive Compatibility:} If \( a < b \), then \( a + c < b + c \).

    \item \emph{Multiplicative Compatibility:} If \( 0 < a \) and \( 0 < b \), then \( 0 < ab \).

\end{enumerate}

These properties ensure that arithmetic operations respect the order structure.

\subsubsection{Consequences of the Order Axioms}

\begin{itemize}

	\item \( a < b \implies -b < -a \)

	\item \( a < b \land c < 0 \implies ac > bc \)

    \item \(a < 0, b < 0 \implies a + b < 0\) the contrary applies to the multiplication \(ab > 0\)

    \item \(a > 0, b > 0 \implies a + b > 0\)
	
    \item Squares are always non-negative: \( a^2 \ge 0 \)

	\item The order is total: any two elements are comparable

\end{itemize}

\subsubsection{Examples of Ordered Fields}

\begin{itemize}

	\item \( \Q \): Rational numbers with the usual order

	\item \( \R \): Real numbers with the usual order

	\item \( \C \): Complex numbers are not an ordered field, since \( i^2 = -1 < 0 \) 
	      would violate positivity of squares

\end{itemize}
