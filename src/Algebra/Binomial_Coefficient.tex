\chapter{The Binomial Coefficient}

In this short section, we will cover the definition and properties of the \emph{binomial coefficient}.
This object can represent the number of combinations in which we can take \(k\) from \(n\) distinct items.

It is defined as: 

\[
    \binom{n}{k} := \frac{n!}{k!(n-k)!},
\]

or as a product:

\[
    \prod_{j = 1}^{n} \frac{n-k+j}{j},
\]

with \(n\) and \(k\) as natural numbers (for the moment).

\section{Properties of the Binomial Coefficient}

\begin{itemize}
    
    \item \( \binom{n}{k} =  \binom{n}{n - k} \)

    \item \( \binom{n}{k - 1} = \binom{n}{k} \frac{n - k}{k + 1} \)

    \item \( \sum_{k = 0}^{n} \binom{n}{k} = 2^n \)

    \item \( \sum_{k = 0}^{n} \binom{m}{k} = \binom{n + 1}{m + 1} \)

    \item \( \binom{n}{0} = 1 = \binom{n}{n} \)

    \item \( \binom{n}{k} + \binom{n}{k + 1} = \binom{n + 1}{k + 1} \)

    \item \( \binom{n}{k} = {(-1)}^k \binom{k - n - 1}{k} \)

    \item \emph{Pascals Identity}: \( \binom{n}{k} + \binom{n}{k - 1} = \binom{n + 1}{k} \)

\end{itemize}

For 

\[
    \binom{n + 1}{k} = \binom{n}{k - 1} + \binom{n}{k}
\]

we think of it as: ``number of \(k\)-elements subsets of \(S = \{0, 1, \dots, n\}\)''  is equal to 
``number of \(k\)-elements subsets of \(S\) with 0'' plus ``number of \(k\)-elements subset of \(S\) without 0''

\textbf{Proof of Pascal's Indentity:}

\begin{align*}
    \binom{n}{k} + \binom{n}{k - 1} &= \binom{n + 1}{k} \\
    \frac{n!}{k! (n - k)!} + \frac{n!}{(k - 1)!(n - (k - 1))!} &= \frac{(n + 1)!}{k!(n + 1 - k)!} \\ 
    \frac{n!}{k! (n - k)!} + \frac{n!}{(k - 1)!(n - k + 1)!} &= \frac{(n + 1)!}{k!(n + 1 - k)!} \\ 
    \frac{(n + 1 - k)n!}{k! (n + 1 - k)!} + \frac{kn!}{k!(n - k + 1)!} &= \frac{(n + 1)!}{k!(n + 1 - k)!} \\ 
    \frac{(n + 1 - k)n! + kn!}{k! (n + 1 - k)!}  &= \frac{(n + 1)!}{k!(n + 1 - k)!} \\ 
    \frac{n!(n + 1 - k + k)}{k! (n + 1 - k)!}  &= \frac{(n + 1)!}{k!(n + 1 - k)!} \\ 
    \frac{n!(n + 1)}{k! (n + 1 - k)!}  &= \frac{(n + 1)!}{k!(n + 1 - k)!} \\ 
    \frac{(n + 1)!}{k! (n + 1 - k)!}  &= \frac{(n + 1)!}{k!(n + 1 - k)!}
\end{align*}

\QED

\section{Proof that the Binomial Coefficient is a Natural Number}

We will prove this via induction for all \(n \ge k\).

\emph{Base case}: \(k = 0\). 

\[
    \binom{0}{0} = 1, \quad \binom{n + 1}{n + 1} = 1, \binom{n}{0} = 1
\]

\emph{Induction hypothesis}:

\[
    \binom{n}{k} = \frac{n!}{k!(n - k)!}  = \binom{n + 1}{k} - \binom{n}{k - 1}\in \N
\]

\emph{Induction step}: 

We want to prove 

\[
    \binom{n + 1}{k} \in \N
\]

We know that 

\[ 
    \binom{n + 1}{k} = \binom{n}{k} + \binom{n}{k  - 1}
\]

Note that we can manipulate this expression so that 

\[ 
   \binom{n}{k} = \binom{n + 1}{k} - \binom{n}{k  - 1} 
\]


\QED

\section{The Binomial Theorem}

\[
    {(a + b)}^n =\sum_{k = 0}^{n} \binom{n}{k}a^{n - k}b^k
\]

The \emph{binomial}, and later multinomial theorem looks out of place at first, but if we first take a look at the sum 
without the sum without the binomial coefficient, we will notice that \(a^{n - k}b^k\) is just a patter in which the 
power of \(x\) decreases and the one of \(y\) increases. Finally the binomial coefficients just tells us ``how many ways are there to get the 
specific \(a^{n - k}b^k\)''

\textbf{Proof:}

We will prove that the equality holds for any \(n\).

For \(n\), we have \( (a + b)^n = \sum_{k = 0}^{n} \binom{n}{k} a^{n - k} b^k \).

For \(n + 1\), we get:

\[
    (a + b)^{n + 1} =\sum_{k = 0}^{n + 1} \binom{n + 1}{k}a^{n + 1 - k}b^k.
\]

Now, let us manipulate the expression to demonstrate our theorem.

Assume that the statement is true for some integer \(n \ge 0\).

\[
    (a+b)^n = \sum_{k=0}^n \binom{n}{k} a^{n-k} b^{k}.
\]

Now, for some greater \(n\),

\[
    (a+b)^{n+1} = (a+b)(a+b)^n.
\]

Using the induction hypothesis:

\[
    (a+b)^{n+1} = (a+b) \sum_{k=0}^n \binom{n}{k} a^{n-k} b^{k}.
\]

We distribute:

\[
    (a+b)^{n+1} = \sum_{k=0}^n \binom{n}{k} a^{\,n+1-k} b^{\,k}
    + \sum_{k=0}^n \binom{n}{k} a^{\,n-k} b^{\,k+1}.
\]

In the second sum, change the index of summation by setting \(j = k + 1\), then rename \(j\) back to \(k\):

\[
    \sum_{k=0}^n \binom{n}{k} a^{\,n-k} b^{\,k+1}
    = \sum_{k=1}^{n+1} \binom{n}{k-1} a^{\,n+1-k} b^{\,k}.
\]

Now, combine both sums:

\[
    (a+b)^{n+1} = \sum_{k=0}^{n+1} 
    \left( \binom{n}{k} + \binom{n}{k-1} \right)
    a^{n+1-k} b^{k},
\]

where we use the convention \(\binom{n}{k} = 0\) for \(k < 0\) or \(k > n\).

By \emph{Pascal’s Identity}:

\[
    \binom{n}{k} + \binom{n}{k-1} = \binom{n+1}{k}.
\]

Therefore,

\[
    (a+b)^{n+1} = \sum_{k=0}^{n+1} \binom{n+1}{k} a^{\,n+1-k} b^{\,k}.
\]

\QED


\textbf{Example:}

We will expand the binomial \((x + y)^3\) using the binomial theorem with some extra 
information to make it easier to understand. 

First, 

\[
    (x + y)^3 = (x + y)(x + y)(x + y) = \sum_{k = 0}^{3} \binom{3}{k} x^{3 - k} y^k = \binom{3}{0} x^3 + \binom{3}{1} x^2 y + \binom{3}{2} x y^2 + \binom{3}{3} y^3.    
\]

\[
    \begin{array}{|c|c|c|}
    \hline 
        k = 0 & xxx & \binom{3}{0} x^{3 - 0} y^0  \\ 
    \hline 
        k = 1 & xxy + xyx + yxx & \binom{3}{1} x^{3 - 1} y^1 \\ 
    \hline 
        k = 2 & xyy + yxy + yyx  &\binom{3}{2} x^{3 - 2} y^2 \\ 
    \hline 
        k = 3 &  yyy & \binom{3}{3} x^{3 - 3} y^3 \\
    \hline 
    \end{array}
\]

\section{Pascal's Triangle}

This is a triangle built by the recursion \(\binom{n + 1}{k + 1} = \binom{n}{k} + \binom{n}{k + 1}\).

\begin{center}
    \begin{tabular}{>{$n=}l<{$\hspace{12pt}}*{13}{c}}
    0 &&&&&&&1&&&&&&\\
    1 &&&&&&1&&1&&&&&\\
    2 &&&&&1&&2&&1&&&&\\
    3 &&&&1&&3&&3&&1&&&\\
    4 &&&1&&4&&6&&4&&1&&\\
    5 &&1&&5&&10&&10&&5&&1&\\
    6 &1&&6&&15&&20&&15&&6&&1
    \end{tabular}
\end{center}
\vspace{1cm}

Here is the triangle, but with the binomial coefficients:

\begin{center}
    \begin{tabular}{>{$n=}l<{$\hspace{12pt}}*{13}{c}}
    0 &&&&&&&\(\binom{0}{0}\)&&&&&&\\
    1 &&&&&&\(\binom{1}{0}\)&&\(\binom{1}{1}\)&&&&&\\
    2 &&&&&\(\binom{2}{0}\)&&\(\binom{2}{1}\)&&\(\binom{2}{2}\)&&&&\\
    3 &&&&\(\binom{3}{0}\)&&\(\binom{3}{1}\)&&\(\binom{3}{2}\)&&\(\binom{3}{3}\)&&&\\
    \end{tabular}
\end{center}

It can be used with the Binomial Theorem to get the coefficients of a polynomial of degree \(n\).

\textbf{Example:}

\[
    {(a + b)}^2 = 1 a^2 b^0 + 2 a^1 b^1 + 1 a^0 b^2,
\]

or

\[
    {(a - b)}^2 = 1 a^2 b^0 - 2 a^1 b^1 + 1 a^0 b^2.
\]
