\chapter{Fractions, Roots, and Exponents}

This is a brief chapter to review the properties of fractions, roots, and exponents. 
It is not a complex chapter, but it is useful to include it in the compendium.

The following statements apply for all \(a, b \in \R\).

\section{Properties of Fractions}

\begin{itemize}

    \item \emph{Addition}: \(\frac{a}{b} \pm \frac{c}{d} = \frac{ad \pm bc}{bd}\).

    \item \emph{Multiplication}: \(\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}\).
        
    \item \emph{Division}: \(\frac{a}{b} \div \frac{c}{d} = \frac{ad}{bc}\).
   
    \item \emph{Reciprocal}: \(\frac{a}{b} = \frac{1}{\frac{b}{a}}\).
  
    \item \emph{Equality}: \(\frac{a}{b} = \frac{c}{d} \iff ad = bc\).
 
    \item \emph{Simplification}: \(\frac{ac}{bc} = \frac{a}{b}\).

\end{itemize}

\section{Properties of Roots and Exponents}

\begin{itemize}

    \item \emph{Multiplication}: \(\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}\).

    \item \emph{Quotient}: \(\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}\).

    \item \emph{Nested Roots}: \(\sqrt[nm]{a} = \sqrt[n]{\sqrt[m]{a}}\).

    \item \emph{Factor Outside Root}: \(a\sqrt[n]{b} = \sqrt[n]{a^n b}\).

    \item \emph{Multiplication}: \(a^m \cdot a^n = a^{m+n}\).

    \item \emph{Division}: \(a^m \div a^n = a^{m-n}\).

    \item \emph{Power of a Power}: \({(a^m)}^n = a^{mn}\).

    \item \emph{Negative Exponent}: \(a^{-n} = \frac{1}{a^n}\).

    \item \emph{Fractional Exponent}: \(a^{\frac{m}{n}} = \sqrt[n]{a^m}\).

    \item \emph{Square Root}: \(a^{\frac{1}{2}} = \sqrt{a}\).

    \item \emph{Cube Root}: \(a^{\frac{1}{3}} = \sqrt[3]{a}\).

    \item \emph{Nth Root}: \(a^{\frac{1}{n}} = \sqrt[n]{a}\).

    \item \emph{Zero Exponent}: \(a^0 = 1\).

    \item \emph{Identity Exponent}: \(a^1 = a\).

\end{itemize}
