\section{Probability}

\subsection{Basics}

A probability experiment is considered ideal if and only the following properties: 

\begin{itemize}
   
    \item We know the possible outcomes. 

    \item It can be repeated multiple times under the same conditions.

    \item It will be executed under strict conditions.

\end{itemize}

\subsection{The Birthday Paradox}

This is a small question that says: What is the probability of at least two people having 
their birthday on the same day in a group of \(x\) persons.

\[
    \prob(x) = 1 - \prod_{n = 0}^{x} \frac{365 - n}{365}
\]

This formula gives us the probability of total minus all persons having it on different days. Which
what we are looking for.

\subsection{The Sample Space}

The set of all possible outcomes of an experiment is denoted as \(\Omega\) and its cardinality 
is the number of possible outcomes.

For experiments with \(\Omega\) as the result set of one repetition then we define 

\[
    \Omega = \Omega \times \cdots \times \Omega  
\]

As the \emph{sample space} of the experiment.

Finally, each subset of \(\Omega\) is called an \emph{outcome}, each subset with 
only one element in it is called an \emph{elemental outcome} The set of all possible outcomes is 
\(\mathcal{P}(\Omega)\)

\subsection{Laplace Distribution and Expceriment}

A \emph{Laplace distribution} is a probability experiment with finite outcomes where 
each elemental outcome has the same probability of occurring.

\[
    \prob(\omega) = \frac{\omega}{|\Omega|}
\]

Then an experiment with this property is considered a \emph{Laplace experiment}.

\[
    \prob(E) = \frac{E}{|\Omega|}
\]

\subsection{Sigma Algebra}

Given a non-empty set \(\Omega\) and \(\mathcal{A} \subseteq \mathcal{P}(\Omega)\) a set 
of subsets of \(\Omega\). \(\mathcal{A}\) is a \(\sigma\)-Algebra if and only if 

\begin{enumerate}[label=\Roman*.]
    
    \item \(\Omega \in \mathcal{A} \) 

    \item \(A \in \mathcal{A} \implies A^c \in \mathcal{A} \)

    \item \(A_1, A_2, A_3, \dots \in \mathcal{A} \implies \bigcup_{n \in \N} A_n \in \mathcal{A} \)

\end{enumerate}

\subsubsection{The Power-set is a Sigma Algebra}

This proof is pretty straight forward. 

For the first axiom, we know that \(\Omega \in \mathcal{P}\). 

For the second axiom, if \(A\) is a subset of the power-set then \(\Omega \setminus A\) is also 
int the power-set.

And lastly, for a sequence of sets in the power-set their, union is also in the power-set, because the power-set 
contains all subsets of \(\Omega\).

\QED

\subsubsection{Properties of Sigma Algebras}

If \(\mathcal{A}\) is a sigma algebra then 

\begin{itemize}
    
    \item \(\emptyset \in \mathcal{A}\) 

    \item \(A_1, A_2, \dots \in \mathcal{A} \implies \bigcap_{n \in \N} A_n \in \mathcal{A}\)

    \item \(A, B \in \mathcal{A} \implies A \setminus B \in \mathcal{A}\)

\end{itemize}

\textbf{Proof:}

For the first, because \(\mathcal{A}\) is a subset of the power-set of \(\Omega\) and the empty set is 
always a subset of a collection, this is trivial. 

Given a number of sets in \(\mathcal{A}\), using the laws of De Morgan we get 

\[
    \bigcap_{n \in \N} A_n = \bigcup A_{n}^{c}
\]

and we know that the complements are part of \(mathcal{A}\) by definition. 

For the last part, \(A \setminus B = A \cap B^c\), because \(B^c \in \mathcal{A}\) we can apply De Morgan 
\((A^c \cup (B^c)^c)^c = (A^c \cup B)^c\) Now because this is the union of two sets in the sigma algebra, and we know by definition 
that their union if also in the set.

\QED

\subsection{Probability Measurement}

Given a non-empty set \(\Omega\) and \(\mathcal{A} \subseteq \mathcal{P}\) a sigma algebra. We define 
the function \(\prob:\mathcal{A} \to \R\) as a \emph{probability measurement} if 

\begin{enumerate}[label=\Roman*.]
    
    \item \(\forall A \in \mathcal{A}: \prob(A) \ge 0\)

    \item \(\prob(\Omega) = 1\) 

    \item \(A_n \in \mathcal{A}, n \in \N \text{ disjunctive in pairs } \implies \prob\left(\bigcup_{n \in \N} A_n\right) = \sum_{n \in \N} \prob(A_n)\) 

\end{enumerate}

Also, the triplet \(\Omega, \mathcal{A}, \prob\) is called a \emph{probability space}.

\subsubsection{Probability space of the Power-set}

We want to prove that the probability space with the power-set of omega and \(\prob(A) = \frac{|A|}{|\Omega|}\) is in fact a probability space 

\begin{itemize}
    
    \item \(\prob(A) = \frac{|A|}{|\Omega|}\) is always greater or equal to zero.
    
    \item \(\prob(\Omega) = \frac{|\Omega|}{|\Omega|} = 1\) 

    \item If all of our subsets in the power-set are pairwise disjunctive this mean that their intersection is the empty-set. In other wise there 
          therefore, their independent of each other which means that their probabilities are also independent.

\end{itemize}

\subsubsection{Discrete Probability Spaces}

A probability space \(\Omega, \mathcal{P}(\Omega), \prob\) is considered \emph{discrete} if 
\(\Omega\) is finite or infinite countable. In that case \(\Omega = \{\omega_i : i \in I\}\) for \(I = \{1, \dots, n\}\) 

For \(A \in \mathcal{A}\)

\[
    \prob(A) = \prob\left( \bigcup_{i \in I: \omega_i \in A} \{\omega_i\}\right) = 
    \sum_{i \in I: \omega_i \in A} \prob(\{\omega_i\}) = \sum_{i \in I: \omega_i \in A} p(\omega_i)
\]

The function \(\prob(\{\omega_i\}) = p(\omega_i)\) is called a \emph{probability function}

To test if specific function or distribution is actually a probability one we have to check.

\begin{itemize}
    
    \item \(\forall p(\omega) \ge 0 \mid \omega \in \Omega\) 

    \item \(\sum_{\omega \in \Omega} p(\omega) = 1\)

\end{itemize}

\subsubsection{Properties of Probability-Measurements}

Given \((\Omega, \mathcal{A}, \prob)\) and \(A,B \in \mathcal{A}\)


\begin{itemize}

    \item \( \prob(\emptyset) = 0 \)
    
    \item \( A_1, \ldots, A_n \in \mathcal{A} \) pairwise disjoint: \( \prob\left(\bigcup_{i=1}^n A_i\right) = \sum_{i=1}^n \prob(A_i) \)
    
    \item \( \prob(B \setminus A) = \prob(B) - \prob(A \cap B) \)
    
    \item \( \prob(A \cup B) = \prob(A) + \prob(B) - \prob(A \cap B) \)
    
    \item \( \prob(A^c) = 1 - \prob(A) \)
    
    \item If \( A \subset B \), then \( \prob(A) \le \prob(B) \)
    
    \item \( 0 \le \prob(A) \le 1 \)

    \item \( A_1, \ldots, A_n \in \mathcal{A} \): \( \prob\left(\bigcup_{i=1}^n A_i\right) \le \sum_{i=1}^n \prob(A_i) \)
    
    \item \( A_1, A_2, \ldots \in \mathcal{A} \): \( \prob\left(\bigcup_{i=1}^{\infty} A_i\right) \le \sum_{i=1}^{\infty} \prob(A_i) \)

\end{itemize}

\textbf{Proof:}

\begin{itemize}

    \item Define \(A_n = \emptyset\) and by the properties of the probability spaces we know that  
    \(A_n \in \mathcal{A}, n \in \N \text{ disjunctive in pairs } \implies \prob\left(\bigcup_{n \in \N} A_n\right) = \sum_{n \in \N} \prob(A_n)\) 
    
    Therefore, \(\prob(\emptyset) = \sum_{i = 1}^{n} \prob(A_i)\) and the only real number with the property \(x + x = x\) is 0.
    
    \item By definition  
   
    \item \(B = (A \cap B) \cup B \setminus A\) and by the definition of the addition of probabilities 
    \[
	\prob(B) = \prob(B \setminus A) - \prob(A \cap B)
    \]
    
    \item Using the addition property and by writing the union as \((A \setminus B) \cup (B \setminus A) \cup (A \cap B)\)we get that 

    \[
	\prob(A \cup B) = \prob(B) - \prob(A \cap B) + \prob(A) - \prob(A \cap B) + \prob(A \cup B)	
    \]

    which results in \( \prob(A \cup B) = \prob(A) + \prob(B) - \prob(A \cap B) \)
 
    \item \(\Omega = A^c \cup A\) and \(1 = \prob(\Omega)\), thus by the addition \(P(A) + P(A^c) = 1\) 
    
    \item Given that if \(A = B\) then the equality holds the case where \(A\) is a subset of \(B\) comes 
    from the fact that it is a strict subset of the other than its cardinality is smaller.
    
    \item By the definition that \(\prob(\Omega) = 1\) and the property \(\prob(\emptyset) = 0\) 
    we are given an upper and lower bound for our probability distribution. Therefore, every subset of \(\Omega\) will 
    have a probability less or equal to it. For the lower bound the logic is that it has no other subset with fewer elements than it, but 
    it is part of sets with more elements.
    
    \item Let us define \(B_n = A_n \setminus \bigcap{i = 1}_{n - 1} A_i\) which are pairwise disjoint. 
    
    \[
	    \prob\left(\bigcup A_n\right) = \prob\left(\bigcup B_n\right) = \sum \prob\left(B_i\right) \le \sum \prob\left(A_i\right)
    \]
    
    Due to the fact that the \(B_i\) are pairwise disjoint.

    \item This is practically the same but for an infinite case.  

\end{itemize}

\QED

\subsection{Stochastic Independence} 

Two results \(A, B \in \mathcal{A}\) are considered \emph{independent} if 

\[
    \prob (A \mid B) = \prob (A)
\]
\[
    \prob (B \mid A) = \prob (B)
\]

then 

\[
    \prob(A \cap B) = \prob(A) \cdot \prob(B) 
\]


\textbf{Example:}

When throwing a diece two times is the probability of throwing during the first throw an even 
number and when throwing the second dice the sum gives us an even number. 

\[
    \Omega = \{1, \dots, 6\}^2 \quad A = \{2,4,6\} \times \{1, \dots, 6\} \quad B = \{2,4,6\} \cup \{1,3,5\}^2
\]

Therefore, 

\[
    \prob(A) = \frac{|A|}{|\Omega|} = \frac{18}{36} = \frac{1}{2}
\]

\[
    \prob(B) = \frac{|B|}{|\Omega|} = \frac{18}{36} = \frac{1}{2}
\]

And  

\[
    \prob(A \cap B) = \frac{| \{2,4,6\}^2| }{|\Omega|} = \frac{1}{4}
\]

This is just \(\prob(A) \cdot \prob(B)\). Therefore, they are independent.

\QED

\subsubsection{Complement Property}

Given the probability space \((\Omega, \mathcal{A}, \prob)\) and \(A, B \in \mathcal{A}\) as two 
independent results. Then \(A^c\) and \(B\) are also independent.

\textbf{Proof:}

The sets \(A \cap B\) and \(A^c \cap B\) are disjoint and their union is 

\[
    B = (A \cap B) \cup  (A^c \cap B)
\]

If we calculate the probability 

\[
    \prob(B) = \prob(A \cap B) +  \prob(A^c \cap B)
\]

This gives us 

\[
    \prob(A^c \cap B) = \prob(A) - \prob(A \cap B)
\]

Using the Independence of \(A\) and \(B\)

\[
    \prob(A^c \cap B) = \prob(B) - \prob(A)\prob(B) = \prob(B) (1 - \prob(A))
\]

\[
    \prob(B) = \prob(B) (1 - \prob(A)) = \prob(B) \cdot \prob(A^c)
\]

\QED

\subsection{The Product Space}

Given two or more probability spaces with their respective tuples of two independent experiments. We define their 
combined probability space as the \emph{product space} where 

\[
    \Omega := \Omega_1 \times \cdots \times \Omega_n
\]

and

\[
    p(\omega_1, \dots, \omega_n) = p(\omega_1) \cdot \dots \cdots p(\omega_n)
\]

An example is throwing two dices at the same time.

\subsection{The Product Space of Discrete Probability Spaces}

Given the product space \((\Omega, \mathcal{P}(\Omega), \prob)\) of the spaces \((\Omega_i, \mathcal{P}(\Omega_i), \prob_i)\) and 
\(A_i \in \mathcal{P}(\Omega_i)\).We define 

\begin{align*}
    A_{i}^{'} &:= \{\omega \in \Omega : \omega_i \in A_i\} \\ 
	      &= \{(w_1, \dots, w_n) : \omega_j \in \Omega_j, \text{ for } j \neq i \text{ and }\omega_i \in A_i\} \\
	      &= \Omega_1 \times \cdots \times \Omega_{i - 1} \times A_i \times \Omega_{i + 1} \times \cdots \times \Omega_n
\end{align*}

For \(i = 1, \dots, n\). Then it holds that \(\prob(A_{i}^{'}) = \prob_i(A_i)\) and the events \(A_{i}^{'}\) are 
independent.

\subsection{Bernoulli-Expceriments}

An experiment where \(\Omega = \{0,1\}, \prob(\{1\}) = p\) and \(\prob(\{0\}) = 1 - p\) for 
\(p \in (0, 1)\) is called a \emph{Bernoulli-Expceriment}.

\subsubsection{Bernoulli Schema}

If we perform a Bernoulli-Expceriment \(n\)-times with a success probability of \(p\). Where 
\(\prob(A_i) = p\). We define 

\[
    C_k = \bigcup_{I \in \{1, \dots, n\} \land |I| = k} \left(\bigcap_{i \in I} A_i \cap \bigcap_{i \in I} A_{i}^{c}\right)
\]

For the probability we get 

\[
    \prob(C_k) = \sum_{I \in \{1, \dots, n\} \land |I| = k} \prob \left(\bigcap_{i \in I} A_i \cap \bigcap_{i \notin I} A_{i}^{c}\right) = 
    \sum_{I \in \{1, \dots, n\} \land |I| = k} \prod_{i \in I} \prob(A_i) = \prod_{i \notin I} = \binom{n}{k} p^k (1 - p)^{n - k}
\]

\subsection{Conditional Probability}

Given the events \(A\) and \(B\) where \(\prob(A) > 0\). The \emph{conditional probability} 
of \(B\) under the condition \(A\) is defined as 

\[
    \prob(B \mid A) = \frac{\prob(A \cap B)}{\prob(A)}
\]

\textbf{Example:}

In words, what is the probability of \(B\) if we limit ourself only to the case where \(A\) happens. Also what is the ratio between \(A \cap B\) and \(A\).
From this definition we can also derive these two statements which are also equivalent. 

\[
    \prob(B \mid A) = \prob(B) \iff A \text{ and } B \text{ are independent}
\]

\textbf{Proof:}

\begin{align*}	
    \prob(B \cap A) = \prob(A)\prob(B) &= \prob(A \cap B){\prob(A)}\\ 
    &= \prob(B)	
\end{align*}

\QED 

\subsubsection{Conditional Probability of a Subset} 

Given the events \(A\) and \(B\) where \(\prob(A) > 0\). If \(A \subset B\) then 
\(\prob(B \mid A) = 1\)

\textbf{Proof:}

\(A \subset B \implies A \cap B = A \) therefore 

\[
    \prob(B \mid A) = \frac{\prob(A)}{\prob(A)} = 1
\]

\QED

\subsubsection{Multiplication Theorem}

Given \(A_1, \dots, A_n\) events with \(\prob(A_1 \cap \cdots \cap A_{n - 1}) \ne 0\). Then 

\[
    \prob(A_1 \cap \cdots \cap A_n) = \prob(A_1)\cdot\prob(A_2 \mid A_1) \cdot \dots \cdot \mathbb(A_n \mid A_1 \cap \dots \cap A_{n - 1})
\]

\subsubsection{Theorem of the Total Probability}

Given our standard probability space, the disjoint partitions of \(\Omega\), \(B_1, \dots, B_n\) where 
\(B_1 \cup \dots \cup B_n = \Omega\), \(B_i \cap B_j = \emptyset\) for \(i \neq j\) and \(\prob(B_i) > 0\) then 

\[
    \prob (A) = \sum_{i = 1}^{n} \prob(A \cap B_i) = \sum_{i = 1}^{n}\prob (A \mid B_i )\prob(B_i) \forall A \in \mathcal{A}
\]

\textbf{Example:}

You are given three bags 

\begin{itemize}
	
    \item Bag A has 2 red balls and 3 green balls 

    \item Bag B has 3 red balls and 2 green balls 

    \item Bag C has 1 red ball and 4 green balls

\end{itemize}

What is the probability of a ball being red? 

The answer is given by

\[
    \prob(R) = \prob (R \cap A) + \prob (R \cap B) + \prob (R \cap C) 
\]

Which gives us 

\[
    \prob(R) = \prob (R \mid A)\prob (A) + \prob (R \mid B) \prob(B) + \prob (R \mid C) \prob(C)
\]

Finally we plug in the individual numbers 

\[
    \prob(R) = \frac{1}{3} \left(\frac{2}{5} + \frac{3}{2} + \frac{1}{4} \right) = \frac{6}{15}
\]

\subsection{Multistage Random Expceriments}

Let \(\Omega_1, \ldots, \Omega_n\) be discrete sample spaces of \(n\) sub-experiments, and let \(\Omega = \Omega_1 \times \cdots \times \Omega_n\).
Furthermore, let an initial distribution be given by the probability function \(p_1\) with

\[
    \sum_{\omega_1 \in \Omega_1} p_1(\omega_1) = 1
\]

and transition probabilities \(p_j\) for \(j = 2, \ldots, n\) satisfying

\[
    \sum_{\omega_j \in \Omega_j} p_j(\omega_j \mid \omega_1, \ldots, \omega_{j-1}) = 1,
\]

for \((\omega_1, \ldots, \omega_{j-1}) \in \Omega_1 \times \cdots \times \Omega_{j-1}\).

This is used in the case when we model our experiment as a tree of probabilities.

For the multistage random experiment, the following two \emph{path rules} apply:

\begin{enumerate}

    \item Let \((\omega_1, \ldots, \omega_n) \in \Omega\). Then we have:
	\[
	    p(\omega_1, \ldots, \omega_n)
	    = p_1(\omega_1) \cdot p_2(\omega_2 \mid \omega_1) \cdot \ldots \cdot p_n(\omega_n \mid \omega_1, \ldots, \omega_{n-1})
	\]

    \item For \(A \subset \Omega\), it holds that
	\[
	    \prob(A) = \sum_{(\omega_1, \ldots, \omega_n) \in A} p(\omega_1, \ldots, \omega_n)
	\]
\end{enumerate}

Note that for independent sub-experiments, we obtain the product space with

\[
    p(\omega_1, \ldots, \omega_n)
    = p_1(\omega_1) \cdot p_2(\omega_2) \cdot \ldots \cdot p_n(\omega_n).
\]

\subsection{Bayes Theorem}

Let \((\Omega, \mathcal{A}, \prob)\) be a probability space. 
Furthermore, let \(B_1, \ldots, B_n\) be a disjoint partition of the sample space \(\Omega\) with \(\prob(B_i) > 0\) for all \(i = 1, \ldots, n\).
Then, for every event \(A \in \mathcal{A}\), the following holds:

\[
    \prob(B_i \mid A)
    = \frac{\prob(A \mid B_i)\,\prob(B_i)}{\prob(A)}
    = \frac{\prob(A \mid B_i)\,\prob(B_i)}{\sum_{k=1}^{n} \prob(A \mid B_k)\prob(B_k)}.
\]

In words and by changing \(A\) with \(E\) of evidence and \(B\) with \(H\) of hypothesis, we want to know how much the actual evidence changes 
our initial belief. The process can be described as: you have a hypothesis, you have observed some evidence and finally, you want to know 
the probability that your hypothesis is true given the observed evidence.

\[
    \prob(H \mid E) = \frac{\prob(E \mid H) \prob(H)}{\prob(H)\prob(E \mid H) + \prob(\neg H)\prob(E \mid \neg H)}
\]

\begin{itemize}
	
    \item \(\prob(H)\) is called the \emph{prior}. Our initial hypothesis, without seeing the evidence.

    \item \(\prob (E \mid H)\) is called the \emph{likelihood}. This is the probability that we will see our hypothesis reflected on the 
    evidence given that our hypothesis is true.

    \item \(\prob (E \mid \neg H)\) represents the probability that our hypothesis will be reflected on the sample given our hypothesis is false. 
    
\end{itemize}

With this knowledge, breaking down the formula is very intuitive 

\begin{itemize}
    
    \item \(\prob (H \mid E)\) is the \emph{posterior}. It describes the following question: How often is \(H\) true among the cases where \(H\) is true.probability

    \item \(\prob(H)\prob(E \mid H)\) is the proportion of our hypothesis in the sample being true times the actual proportion of the fitting samples inside our hypothesis. 

    \item \(\prob(H)\prob(E \mid H) + \prob(\neg H)\prob(E \mid \neg H) \) consist of our expression above plus the proportion of the counter hypothesis times the proportion of the 
    representatives of our hypothesis which will show up in the evidence in the counter group.

\end{itemize}

\textbf{Example:}

A disease affects 1 percent of the population, and you were tested positive with a test which has a 99.9 percent accuracy. What is 
the probability for you truly being infected? 

\[
    \prob ( I \mid + ) = \frac{\prob(I)\prob(+ \mid I)}{\prob(I)\prob(+ \mid I) + \prob( \neg I) \prob( + | \neg I)}
\]

Our numbers are: 

\begin{itemize}
	
    \item \(\prob(I) = 0.001 \)

    \item \(\prob (+ \mid I) = 0.99\) 
    
    \item \(\prob(\neg I) =  0.999\)

    \item \(\prob (+ \mid \neg I) = 0.1\)  
    
\end{itemize}

Thus, our formula gives us a 9 percent chance of actually being infected.

\subsection{Law of Large Numbers}

Given a sequence of independent random variables \(X_1, X_2, \dots, X_n\) with the same 
mean \(\mu\) and the same \(\sigma^2\). The sample mean \(Z_n = \frac{1}{n} \sum_{i = 1}^{n}X_i\) will 
converge to \(\mu\) as \(n \to \infty\).

Formally \(P(|Z_n - \mu| > \epsilon)_{n \to \infty} \to 0\).

\textbf{Proof:}

Since our random variables are independent 

\[
    \expc[Z_n] = \frac{1}{n} \sum_{i = 1}^{n} \expc[X_i] = \mu
\]

\[
    \var[Z_n] = \frac{1}{n} \sum_{i = 1}^{n} \var[X_i] = \frac{\sigma^2}{n}
\]

as \(n \to \infty, \var(X) \to \infty\).

Formally, 

\begin{align*}
    \prob(|Z_n - \mu | \ge \varepsilon) &\le \frac{\var(Z_n)}{\varepsilon^2} \\ 
    & \frac{\sigma^2}{n \varepsilon^2} \to 0 \text{ as n goes to infinity}
\end{align*}

\subsection{Strong Law of large Numbers}

Given \(X_1, X_2, \dots\) independent random variables with the same distribution and \(|\expc|X_1| < \infty\) then

\[
    Z_n \to \expc[X_1]
\]

where \(Z_n = \frac{1}{n} \sum_{i = 1}^{n}X_i\)

\subsection{Central Limit Theorem}

Given the same conditions of the \emph{Law of large Numbers}. The sample mean 

\[
    Z_n = \frac{1}{n} \sum_{i = 1}^{n}X_i \sim \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)
\]

or equivalently

\[
    \lim_{n \to \infty} \prob \left(\sqrt{n} \frac{Z_n - \mu}{\sigma} \le x\right) = \Phi (x)
\]

\textbf{Example:}

Approximate the probability of a tricked coin landing heads with \(n = 10000\) throws and the number of 
heads between \(4900 < X < 5100\).

Our variable is binomial distributed 

\[
    \mu = \expc[X] = np = 5000
\]

\[
    \sigma = 50
\]

Then for  

\[
    \prob \left( Z_1 \le \sqrt{n} \frac{Z_n - \mu}{\sigma} \le Z_2 \right)
\]

with \(Z_1 = \frac{4900 - 5000}{50}, Z_2 = \frac{5100 - 5000}{50}\)
We get 

\[
    \Phi(Z_2) - \Phi(Z_1) = 0.9545
\]

\subsection{Approximating the Binomial Distribution with the Normal Distribution}

Given a binomial distribution with parameters \(n\) and \(p\). For large \(n\) the distribution can be approximated
by a normal distribution with parameters \(\mu = np\) and \(\sigma = \sqrt{np(1 - p)}\).

\textbf{Example:}

Given \(n = 75\) and \(p = 0.6\) approximate the probability of getting between \(\prob(X \ge 52)\)

\(\mu = np = 45\), \(\sigma^2 = np(1 - p) = 18\)

\[
    Z = \frac{X - \mu}{\sigma} = \frac{X - 45}{\sqrt{18}}
\]

Therefore,

\[
    \prob \left( Z \ge \frac{52 - \mu}{\sqrt{18}} \right)
\]

\[
    = 1 - \Phi \left( \frac{52 - 45}{\sqrt{18}} \right) = 0.0582
\]

For \(\prob( 50 \le X \le 52)\) we have 

\[
    \prob \left( \frac{50 - \mu}{\sqrt{18}} \le Z \le \frac{52 - \mu}{\sqrt{18}} \right) = \Phi \left( \frac{52 - 45}{\sqrt{18}} \right) - \Phi \left( \frac{50 - 45}{\sqrt{18}} \right)
\]

\subsection{Theorem of Moivre-Laplace}

Given \(X_1, X_2, \dots, X_n\) Bernoulli distributed random variables and \(S_n = \sum_{i = 1}^{n} X_i\) then the 
number of successes is given by 

\[
    \lim_{n \to \infty} \prob \left( \frac{S_n - np}{\sqrt{np (1 - p)} \le x}\right) = \Phi(X)
\]

For the case that we have a region with two bounds \(a < S_n < b\) we get

\[
    \prob \left( \frac{S_n - np}{\sqrt{np (1 - p)} \le Z_2}\right) - \prob \left( \frac{S_n - np}{\sqrt{np (1 - p)} \le Z_1}\right)
\]

If normal approximation is used for a discrete distribution we have to apply the continuity correction.

\[
    \prob (a < S_n < b) \approx \Phi \left( \frac{b + 0.5 - np}{\sqrt{np(1 - p)}}\right) - 
    \Phi \left( \frac{a - 0.5 - np}{\sqrt{np(1 - p)}}\right)
\]

\subsubsection*{Continuity Correction}

An approximation is useful if \(np(1 - p) \ge 9\)


\textbf{Example:}

Approximate the probability of getting between \(4900 < X < 5100\) heads when throwing a tricked coin
\(n = 10000\) times with \(p = 0.5\).

\[
    \prob \left( \frac{S_n - np}{\sqrt{np (1 - p)} \le Z_2}\right) - \prob \left( \frac{S_n - np}{\sqrt{np (1 - p)} \le Z_1}\right)
\]

with \(Z_1 = \frac{4900 - 5000}{50}, Z_2 = \frac{5100 - 5000}{50}\)

\[
    \Phi(Z_2) - \Phi(Z_1) = 0.9545
\]

The complete formula for this case looks like this

\[
    \prob (4900 < S_n < 5100) \approx \Phi \left( \frac{5100 + 0.5 - np}{\sqrt{np(1 - p)}}\right) - 
    \Phi \left( \frac{4900 - 0.5 - np}{\sqrt{np(1 - p)}}\right)
\]
