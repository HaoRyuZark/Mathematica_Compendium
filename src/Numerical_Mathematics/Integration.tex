\chapter{Numerical Integration}

The main idea of the numerical integration is to find a function \(g(x)\) which is easier to integrate, instead 
of integrating \(f(x)\) directly.

\section{Newton Cotes}

Given \(- \infty < a < b < \infty \) and \(f \in [a,b]\) we want to approximate 

\[
    \int_a^b f(x) dx
\]

with use of equidistant points \(x_k = a(b - a)\frac{k}{n} \in [a, b]\) \(k\) being the number of points.
Hence, we use polynomial interpolation which gives us: 

\[
    \int_a^b g(x) dx = (b - a) \sum_{k = 0}^{n} \beta_k f(x_k)
\]

where \(\beta_k\) are the \emph{weights} given by our Newton interpolation algorithm.

It is also a preferred to divide the target interval into sub-intervals and then apply the approximation on those intervals to avoid 
using high degree polynomials.


\[
    \int_a^b f(x) dx = \sum_{i = 0}^{m - 1} \int_{a_i}^{b_i} g(x)
\]

with \(a = a_0 < b_0 = a_1 < b_1 ... a_{m - 1} < b_{m - 1} = b\).

In general, this is the template for the coming methods.

\section{The Midpoint Rule}

The \emph{midpoint rule} builds rectangles by taking the middle point of the sub-intervals as the 
height of our rectangles.

\[
    M_n = \sum_{i = 1}^n f\left(\frac{x_{i - 1} - x_i}{2}\right) h, \quad h - \frac{b - a}{2}
\]

With the error 

\[
    E \le \frac{(b - a)^3}{24 n^2} \max_{a \le x \le b}|f''(x)|
\]

\section{Trapezoidal Sum}

One of the most common approaches for approximating integrals which is very easy to compute is the \emph{trapezoidal sum} which 
consist on dividing our interval \([a,b]\) into \(n\) trapezoids whose area is given by \(\frac{h}{2}(a + b)\). 

\[
    T_n = \frac{h}{2} \left(f(a) + \sum_{i = 1}^{n - 1} f(a + ih) + f(b)\right), \quad h = \frac{b - a}{n}
\]

With the error 

\[
    E \le \frac{(b - a)^3}{12 n^2} \max_{a \le x \le b}|f''(x)|
\]

\section{Simpsons Rule}

The \emph{Simpsons rule} is an improvement of the trapezoidal rule which uses parabolas using two 
intervals in order to  improves the approximation of the sum.

\[
    S_n = \frac{b - a}{3n} \left(f(a) +  \sum_{i = 1}^{n - 1} s(i)f(a + ih)  + f(b)\right)
\]

where

\[
    s(i) = \begin{cases}
        4, & \text{ if } i \text{ odd}\\ 
        2, & \text{ else }
    \end{cases}
\]

With error 

\[
    E \le \frac{(b - a)^5}{180 n^4} \max_{a \le x \le b} |f^{(4)}(x)|
\]

\section{Accuracy}

We can use the error formulas and solve for \(n\) to find the number of sub-intervals to 
use with our approximation given an initial precission. 

\textbf{Example:}

Given \(\int_{-2}^{1} (-x^4 - 2x^3 + 12x^2 + 2x -5 dx)\) find the \(n\) for a result user the Simpsons rule with 
accuracy between 0.1. 

Using our formula 

\[
    E \le \frac{(b - a)^5}{180 n^4} \max_{a \le x \le b} |f^{(4)}(x)|
\]

Assuming we already know our maximum we would get: 

\begin{align*}
    \frac{(1 - (-2))^5}{180 n^4} \max_{a \le x \le b} |f^{(4)}(x)| &\le \frac{1}{10} \\
    \frac{(1 - (-2))^5}{180 n^4} \max_{a \le x \le b} 24  &\le \frac{1}{10} \\
     n &\le  4.24
\end{align*}

Hence we need to use an \(n \ge 4.24\).


\section{Lagrange Integration For \texorpdfstring{\([0, 1]\)}{}}

For the interval \([0,1]\) we get the equidistant points \(x_k = \frac{k}{n}\) giving 
us the interpolation 

\[
    g(x) = \sum_{k = 0}^{n} f(x_k) L_k (x),
\]

where 

\[
    L_k(x) = \prod_{i = 0, i \ne k} \frac{x - x_i}{x_k - x_i}
\]

is our \emph{Lagrange polynomial}.

Using them gives us the approximation 

\[
    \int_1^0 g(x) = \sum_{k = 0}^{n}f(x_k) \int_0^1 L_k (x) dx = \sum_{k = 0}^n \beta_k f(x_k)
\]

with \(\beta_k = \int_0^1 L_k (x) dx\).

\subsection{Generalization For \texorpdfstring{\([a,b]\)}{}}

We can extend the previous idea to any real, closed interval 

\[
    \int_a^b f(x) dx = (b - a) \int_0^1 f(a + (b - a)y) dy \approx (b - a) \sum_{k = 0}^n \beta_k f \left(a + (b - a)\frac{k}{n}\right)
\]

\section{Summation For Error Mitigation}

\[
    \int_a^b f(x) dx = (b - a) \sum_{i = 0}^{m - 1} \int_{a_i}^{b_i} f(x) dx \approx \sum_{i = 0}^{m - 1}(b_i - a_i) \sum_{k = 0}^n \beta_k f(x_{k,i})
\]

with \(a = a_0 < b_0 = a_1 < b_1 ... a_{m - 1} < b_{m - 1} = b\). \(x_{k, i} = a_i + (b_i - a_i)\frac{k}{n}\).

For the case when the intervals have the same size then our intervals boundaries are given by 

\[
    h = \frac{b - a}{m} = b_i - a_i, \quad a_i = a + ih, \, b_i = a + (i + 1)h
\]

\subsection{Bernoulli Polynomials And The Bernoulli Numbers}

The \emph{Bernoulli polynomials} \(b_k\) are defined by 

\[
    b_0(x) = 1, \quad b_k'(x) = k, \ \int_0^1 b_k(x)dx = 0, \, k \ge 1.
\]

The \emph{Bernoulli numbers} are given by 

\[
    B_0 = b_0(0) = b_0(1), \quad B_1 = b_1(0) = -b_1(1), \quad B_k = b_k(0) = b_k(1), \ k \ge 2.
\]

These numbers are used in the next Theorem.

\section{Euler-Maclaurin Summation}

Ist \(f \in C^{2n}([a, b])\) then the following formula holds: 

\[
    \sum_{n = a}^{b} f(n) = \int_a^b f(x) dx + \frac{f(a) - f(b)}{2} + \sum_{n = 1}^{\infty} \frac{B_{2n}}{(2n)!} (f^{(2n - 1)}(b) - f^{(2n - 1)}(a))
\]


This formula is used to approximate integrals without computing a lot of terms.
